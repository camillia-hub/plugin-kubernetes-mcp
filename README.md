# Kubernetes MCP

Operates Kubernetes clusters. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/kubernetes-mcp-server

Installs from the Camillia hub as `kubernetes-mcp-8f8844`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
